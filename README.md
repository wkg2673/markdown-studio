## About

**Markdown Studio** is a single-page, dependency-light Markdown editor inspired
by the feel of Notion, Obsidian, and Typora. It renders GitHub Flavored
Markdown with a live, side-by-side preview, highlights your source as you type,
and keeps every keystroke safe with local autosave.

Everything runs client-side: documents are stored in your browser's
`localStorage` and never leave your device. There is no build step, no bundler,
no framework — just HTML, CSS, and vanilla JavaScript.

## Features

### Editor

- **Split-screen editing** — Markdown source on the left, live rendered
  preview on the right; switch between split, editor-only, and preview-only
  views
- **Draggable divider** to resize the panes (double-click to reset)
- **Syntax highlighting** for Markdown source, plus line numbers that
  follow soft-wrapped lines
- **Find & replace** with match highlighting, match-case toggle, replace-one
  and replace-all
- **Undo / redo** with a smart, typing-aware history stack
- **Smart keys** — lists continue (and renumber) on `Enter`, `Tab` /
  `Shift+Tab` indent and dedent selections
- **Fullscreen mode** for distraction-free writing
- **Synced scrolling** between editor and preview (optional)

### Markdown

- Full **GitHub Flavored Markdown**: tables, task lists, strikethrough,
  autolinks
- **Footnotes** with numbered references and a rendered footnotes section
- **Fenced code blocks** highlighted with highlight.js (dozens of languages)
- Inline code, blockquotes, nested lists, horizontal rules, images, links
- Output is **sanitized with DOMPurify** before it ever touches the DOM
- Preview updates instantly as you type

### Documents

- **Multi-document sidebar** — create, rename, delete, and switch between
  documents without losing changes
- **Autosave** to `localStorage` (with save status in the status bar)
- **Restores your last document** after a page refresh
- **Import** `.md` / `.markdown` / `.txt` files (multiple at once)
- **Export** any document as a `.md` file
- Copy the Markdown source, the rendered HTML, or the preview text
- A print stylesheet that prints just the preview

### Interface

- **Dark theme by default** with a full light theme
- **Formatting toolbar** (headings, emphasis, lists, links, images, code,
  tables, rules) that inserts syntax at the cursor
- **Live statistics** — words, characters, lines, reading time, cursor
  position, current document
- Responsive layout for desktop, tablet, and mobile; reduced-motion support
- Customizable fonts, sizes, line numbers, tab width, and more in Settings

## Technologies used

| Purpose | Choice |
| --- | --- |
| Structure | HTML5 |
| Styling | CSS3 (custom properties, flexbox, `100dvh`, container-aware responsive rules) |
| Logic | Vanilla JavaScript (ES2020+, no framework, no build step) |
| Markdown parsing | [marked.js 12](https://github.com/markedjs/marked) (vendored) |
| HTML sanitizing | [DOMPurify 3](https://github.com/cure53/DOMPurify) (vendored) |
| Code highlighting | [highlight.js 11](https://github.com/highlightjs/highlight.js) (vendored) |
| Icons | [Lucide](https://lucide.dev) inline SVGs (generated by `scripts/build-icons.mjs`) |

The three libraries above are vendored in `vendor/` so the app works offline
and behind firewalls — see [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## Getting started

### Run locally

Because the app uses no build step, you can serve it with any static file
server. For example, with Python:

```bash
cd markdown-studio
python -m http.server 8000
# open http://localhost:8000
```

Or with Node.js:

```bash
npx serve markdown-studio
```

Opening `index.html` directly from disk also works for a quick look — but a
local server is recommended, since some browsers restrict features on
`file://` pages (clipboard API, storage isolation, and so on).

### Deployment

The project is a fully static site — host it anywhere:

- **GitHub Pages**: push the `markdown-studio` folder contents to a repository
  and enable Pages
- Netlify / Vercel / Cloudflare Pages: drag-and-drop the folder
- Any web server: copy the folder to your document root

## Usage

1. **Start writing** — the welcome document demonstrates every Markdown
   feature; edit or delete it freely.
2. **Manage documents** in the sidebar: `+` creates a new document, hover a
   document for rename / delete, click to switch (changes are saved before
   switching).
3. **Import / export** from the top bar. Exports download as `<title>.md`.
4. **Copy** the Markdown source, rendered HTML, or plain preview text from
   the `⋯` menu.
5. **Search** with `Ctrl+F`; matches are highlighted in the editor and the
   panel supports case-sensitive replace and replace-all.
6. Everything is stored locally per browser — clearing site data deletes your
   documents, so use export for backups.

## Browser compatibility

Tested on the latest versions of **Chrome**, **Edge**, and **Firefox** on
desktop, plus Chrome on Android. The app targets evergreen browsers and uses:

- `localStorage`, `Fetch`, `Promise` (baseline)
- CSS custom properties, flexbox, `100dvh` (with fallback), `:has()` for task
  lists
- Clipboard API with an `execCommand` fallback for non-secure contexts

> Internet Explorer is not supported.
